# AI Image/Text Recognition

An AI-powered OCR system that extracts readable text from uploaded images.

## Objectives
- Extract text using OCR
- Improve recognition with preprocessing
- Display detected text
- Calculate OCR confidence
- Download extracted text

## Technologies
Python, OpenCV, Tesseract OCR, Pytesseract, NumPy, Pillow, Streamlit

## Workflow
Upload Image → Preprocessing → Grayscale → Noise Reduction → Thresholding → Tesseract OCR → Detected Text → Confidence Score → Download
