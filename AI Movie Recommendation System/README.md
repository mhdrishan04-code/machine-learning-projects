# AI Movie Recommendation System

A content-based movie recommendation web application built with Streamlit, Scikit-learn and Pandas.

## Features
- Genre, language and mood preferences
- CountVectorizer + cosine similarity
- Movie title search
- Dynamic poster rendering
- Responsive dark UI

## Files
- app.py
- recommender.py
- movies.csv
- requirements.txt
- logo.png
