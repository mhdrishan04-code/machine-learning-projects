# AI/ML Tasks – Combined Repository

This repository combines the four projects into separate folders for easy submission and maintenance.

## Projects

### Task 1 – NeoChat
Rule-based AI/ML learning chatbot.
- `Task-1/chatbot.py`
- `Task-1/requirements.txt`

### Task 2 – Iris Classification
K-Nearest Neighbors classification using the Iris dataset, with accuracy, confusion matrix and weighted F1 score.
- `Task-2/classificatin.py`
- `Task-2/requirements.txt`

### Task 3.1 – AI Movie Recommendation System
Streamlit movie recommender using CountVectorizer and cosine similarity.
- `Task-3.1/app.py`
- `Task-3.1/recommender.py`
- `Task-3.1/movies.csv`
- `Task-3.1/requirements.txt`

Run from the Task-3.1 directory:
`streamlit run app.py`

### Task 4 – AI Text Recognition
Streamlit OCR application using OpenCV and Tesseract.
- `Task-4/app.py`
- `Task-4/main.py`
- `Task-4/requirements.txt`
- `Task-4/packages.txt`

Run from the Task-4 directory:
`streamlit run app.py`

## Notes

The original repositories remain unchanged. This repository contains the combined runnable source code and a compact movie dataset. Binary media assets from the original repositories (images/video) were not copied through the connected GitHub file interface.
