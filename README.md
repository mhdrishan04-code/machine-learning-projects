# AI/ML Projects – Combined Repository

This repository combines four AI/ML projects into separate folders for easy submission and maintenance.

## Projects

### 1. Rule-based AI/ML learning chatbot
Rule-based AI/ML learning chatbot.
- `Rule-based AI/ML learning chatbot/chatbot.py`
- `Rule-based AI/ML learning chatbot/requirements.txt`

### 2. Iris Classification
K-Nearest Neighbors classification using the Iris dataset, with accuracy, confusion matrix and weighted F1 score.
- `Iris Classification/classificatin.py`
- `Iris Classification/requirements.txt`

### 3.1 AI Movie Recommendation System
Streamlit movie recommender using CountVectorizer and cosine similarity.
- `AI Movie Recommendation System/app.py`
- `AI Movie Recommendation System/recommender.py`
- `AI Movie Recommendation System/movies.csv`
- `AI Movie Recommendation System/requirements.txt`

Run from the AI Movie Recommendation System directory:
`streamlit run app.py`

### 4. AI Text Recognition
Streamlit OCR application using OpenCV and Tesseract.
- `AI Text Recognition/app.py`
- `AI Text Recognition/main.py`
- `AI Text Recognition/requirements.txt`
- `AI Text Recognition/packages.txt`

Run from the AI Text Recognition directory:
`streamlit run app.py`
